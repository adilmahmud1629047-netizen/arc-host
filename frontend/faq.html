General

Getting started

ARC HOST is a hosting platform for Minecraft servers, websites, and virtual private servers. It combines this public site, a customer dashboard, and a plan catalog into one product as the platform rolls out.

Web hosting is the easier, more managed option for websites and small applications. Choose VPS hosting when you need isolated CPU, RAM, and storage for something you want to run end to end.

Region slots shown on this site are placeholders. We only publish specific data center locations once they are actually configured — you will never find invented locations here.

Reliability is a core priority, but we do not publish uptime percentages or SLAs until they are backed by real infrastructure and measurable commitments. This FAQ is where that will be announced.

Web Hosting

About our hosting plans

Web hosting is a service that stores your website's files and makes them available on the internet. ARC HOST web hosting plans handle the underlying server so you can focus on your site.

Every price, limit, and billing cycle on the product pages is read live from the catalog API when you open the page — there are no hand-typed figures. Final commercial terms publish with the billing system.

An upgrade path from web hosting to VPS is part of the platform design. The migration flow will be detailed when the provisioning steps go live.

SSL is a catalog field, not a slogan: the comparison table on the web hosting page marks whether each tier includes it. Check the SSL row of the plan you are considering.

VPS Hosting

About our VPS plans

A Virtual Private Server is a virtualized server with its own allocation of CPU, RAM, storage, and network. It gives you more control and isolation than shared web hosting.

Operating system choices publish with provisioning. Until the platform returns a real list, this site will not name distributions or editions it cannot yet provide.

The vCPU, RAM, storage, and bandwidth figures shown are the catalog's current values. Final hardware profiles publish when VPS provisioning goes live.

Access levels ship with the provisioning documentation. The plan cards list the resources we can guarantee today; the rest is confirmed when servers go live rather than promised ahead of time.

Accounts & Billing

Accounts, payments, and support

Use "Get Started" in the navigation to register. Once you are signed in, your plans, orders, and account details live in the customer dashboard.

Payment options will be shown during checkout when payments are enabled. While payments are disabled, no method is advertised here — and we will never list one we cannot actually accept. Billing cycles and currencies always come from the plan catalog.

Use the contact page — it is the single route for pre-sales and account questions today. After you have an account, the dashboard is where service messages will appear. We do not publish a phone number or mailbox we are not monitoring.

Cancellation and refund policies will be published alongside the billing system, before any real order can be placed.
